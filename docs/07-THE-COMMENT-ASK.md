# The comment ask, inside the picture

Goal: people comment one short word and you send them the resource.

## What the GIF does

1. **A strip at the very top, from the first frame:** `COMMENT [RAW] FOR THE <NAME OF THE RESOURCE> ↓`. White bar, black text, the keyword on a yellow chip, a bobbing arrow towards the comment box (on LinkedIn the comment box sits below the media).
2. **An underline pass:** each word is underlined once, from left to right, one after another, at a slow pace; the last underline finishes right as the screen changes. The keyword gets a bold curved arc in a contrasting colour. The ask is being drawn from the first frame to the screen change.
3. **An end screen** (the main content slides up and blurs out): COMMENT, the keyword on a big bar, a sentence that names the resource, a bonus line, an arrow.

## Rules

- The keyword is short, 3 letters if you can, and matches the topic (here RAW matches "raw footage").
- Name the resource and say what it is worth. "The free resource" converts worse than a named kit.
- Keep the keyword out of the post text. Posts that end with "comment KEYWORD" were reported to get fewer impressions on LinkedIn since mid 2026 (a vendor study of about 687,000 posts). Whether the same penalty applies to a keyword inside a picture is not proven. Measure it on your own account: compare impressions and comments at 3 and 7 days with your recent average.
- Send the resource by hand to each commenter, with the repository home link only. Never a link to a private folder or document.
- Every item named on screen must exist before you post.
