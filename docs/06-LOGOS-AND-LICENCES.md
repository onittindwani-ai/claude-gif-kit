# Logos and licences

Logos belong to their owners. This kit shows them only to name a tool, and only ships files whose licence allows redistribution.

| Files in `public/logos` | Source | Licence of the file |
| --- | --- | --- |
| deepgram, ffmpeg, figma, instagram, tiktok, x (.svg) | simple-icons 16.38.0 (npm) | CC0 1.0 |
| claudecode, codex, gemini, hermesagent, nanobanana (.svg) | @lobehub/icons-static-svg (npm) | MIT |

Marks for Earshot, Palmier Pro, Higgsfield and LinkedIn are not shipped. The template shows a typeset name tile instead. To use the real marks, take them from each project's own brand page or repository, check the licence, and add a file name to the tool entry in `src/Pipeline.tsx` (`{ name: "Higgsfield", file: "higgsfield.png", bg: "#17171B", full: true }`).

Rules we followed: use a logo only to name the tool, never imply an endorsement, keep a licence row for every file, keep every logo the same size in a row.
