# Start here

1. `npm install`
2. `npm run setup` (placeholder clips)
3. `npm run still` then open `out/main.png`
4. `npm run studio` to preview the animation in Remotion Studio
5. `npm run render` then `npm run gif`
6. Read `docs/04-GIF-RECIPE.md` before you upload a GIF anywhere.

To rebuild it for your own idea, open this folder in Claude Code and say:
**use the gif-from-a-sketch skill and rebuild this animation for my idea.** Attach your sketch.
